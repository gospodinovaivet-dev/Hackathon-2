# ChillCheck – MVP app

Main goal only: **door closes → photo → food list with expiry dates → Eat Me First list, sorted by urgency.**

## Run it
Open `index.html` in a browser. No install needed.

## Files
| File | What it does |
|---|---|
| `index.html` | The screens: setup (pairing), home, check the dates, Eat Me First, recipes |
| `css/styles.css` | All styling |
| `js/ui.js` | Shared helpers (element builder, toast) |
| `js/dates.js` | Date helpers |
| `js/store.js` | Saves user, paired fridge and food list (browser storage for now) |
| `js/food.js` | Status rules (Safe / Eat soon ≤2 days / Expired), sorting, merging a new scan into the list, example data |
| `js/photos.js` | List of camera photos. Generated by `build.js`, don't edit |
| `js/scanner.js` | Sends any photo to the AI (fridge, food elsewhere, shop bill), with pixel rulers added so it can place a square around each food; gets back food, freshness and expiry |
| `js/dish.js` | Draws the dish illustration for each recipe |
| `js/recipes.js` | Recipes screen: preferences, "from my fridge" / "anything, I'll shop", AI recipes |
| `js/sensors.js` | Temperature + door sensor (simulated): auto-close after 60 s, alert after 10 min |
| `js/app.js` | Screen logic and buttons |
| `photos/` | Fridge photos used by **Check inside** as the camera's photo |
| `build.js` | Updates `js/photos.js` and bundles everything into `dist/chillcheck.html` for sharing: `node build.js` |
| `archive/` | Earlier all-in-one prototypes (recipes, insights, fridge cam, receipt scan) |

## Where each expiry date comes from (strongest first)
1. **You** edited it
2. **Printed on the pack** (read from the fridge photo, or "Scan date" with the phone)
3. **Receipt** purchase date + typical shelf life
4. **Cooked food rule**: 3 days from the first photo it appeared in
5. **AI estimate** from how the food looks

A weaker source never overwrites a stronger one. Exception: if a new photo shows the food looks spoiled, the date moves earlier. Every photo counts as taken today. The door state comes only from the magnet sensor, never from a photo.

## Testing the fridge camera AI with your own photos
1. Put `.jpg` / `.png` photos of a fridge inside into `photos/`.
2. Run `node build.js`.
3. Open the shared link → **Check inside** → pick a photo. The AI lists each food, how fresh it looks ("AI saw: mould on the top") and an expiry estimate.

## Notes
- Real photo recognition works when the app is opened in Claude. Opened as a local file, use **"Close door with an example photo"**.
- Items seen in an earlier scan keep their (possibly edited) expiry date. Items missing from a new photo are listed so the user can keep or remove them.
